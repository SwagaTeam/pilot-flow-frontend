ВЫБОР ПИЛОТНОГО ПОТОКА — контракт 1.0.0

Начните с handoff.html: правила, карта данных, API и разделение работ.
swagger.html открывается локально, без интернета. Держите файлы Swagger рядом.
openapi.yaml и openapi.json — одна спецификация, 45 операций, 51 схема.
schema.sql находится в https://github.com/SwagaTeam/pilot-flow-backend
database-map.svg — обзор связей; точные связи в schema.sql.
control-example.json — данные и результат из контрольного примера ТЗ.
acceptance-vectors.json — граничные значения для тестов реализации.
validation-report.json — что проверено и какие ограничения остались.
source-audit.json — исходники, SHA-256 и проверенные формулы Excel.

Фронт может запустить: node mock-server.mjs
Затем: http://localhost:5080/swagger.html
Mock только для чтения и UI; не поддерживает запись, расчёт новых данных, PDF.
При подключении настоящего ASP.NET backend остановите mock (Ctrl+C).

БД: psql -v ON_ERROR_STOP=1 -d pilot_db -f schema.sql
Только пустая БД, миграция выполняется один раз.

Стек: ASP.NET Core, C#, PostgreSQL. Приложение пока не создавалось.
Исходники: локальное ТЗ DOCX, PDF методики, XLSM v2.0.
Figma просмотрена через браузер: 41 экран, соответствия в figma-api-map.csv.
API Figma потребовал OAuth, поэтому использован визуальный просмотр.
Неопределённые расчётные правила явно описаны в handoff.html.
